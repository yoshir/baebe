# Investor Landing Experience

**Low-tech aesthetic, high-quality feel**

## Structure

- `index.html` - Main investor landing (typing animation, email collection)
- `movie-pitch.html` - Movie/book pitch page (video background, pseudo-code)
- `styles.css` - Terminal aesthetic styling
- `script.js` - Typing animation logic

## Design Principles

- Black background (#000000)
- Green monospace text (#00ff41)
- Blinking cursor animation
- Typewriter effect
- Subtle video background (15-25% opacity)
- Minimal, focused
- Feels premium through attention to detail
