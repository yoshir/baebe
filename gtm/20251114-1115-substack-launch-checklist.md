# BAEBE: Substack Launch Checklist

**Version:** v.20251114-1115  
**Last Updated:** 2025-11-14  
**Purpose:** Step-by-step checklist to launch BAEBE on Substack

---

## Pre-Launch Checklist (Week 1)

### Account Setup
- [ ] Create Substack account (substack.com)
- [ ] Choose publication name: "BAEBE" or "BAEBE: The Novel"
- [ ] Set up profile (bio, photo, links)
- [ ] Design header image (1920x384px recommended)
- [ ] Design logo/avatar (square, 256x256px recommended)
- [ ] Set up publication description/tagline

### Subscription Tiers Configuration
- [ ] **Free Tier:**
  - [ ] Enable free subscriptions
  - [ ] Set free content (first 2-3 chapters)
  - [ ] Configure free newsletter access

- [ ] **Paid Tier:**
  - [ ] Set monthly price ($5-$10/month recommended)
  - [ ] Set annual price ($50-$100/year recommended)
  - [ ] Write paid tier description
  - [ ] List paid tier benefits:
    - [ ] Full chapter access
    - [ ] Early access to new chapters
    - [ ] Bonus content (behind-the-scenes, character bios)
    - [ ] Exclusive discussions
    - [ ] Community access

- [ ] **Founding Member Tier:**
  - [ ] Set founding member price ($50-$100/year or $10-$20/month)
  - [ ] Write founding member description
  - [ ] List founding member benefits:
    - [ ] All paid tier benefits
    - [ ] Name in book acknowledgments
    - [ ] Signed copy when book launches
    - [ ] Exclusive merchandise (future)
    - [ ] Direct access to author
    - [ ] Lifetime access (if applicable)

### Content Preparation
- [ ] **Welcome Post:**
  - [ ] Write welcome message
  - [ ] Introduce BAEBE and the story
  - [ ] Explain publishing schedule
  - [ ] Set expectations

- [ ] **First 3 Free Chapters:**
  - [ ] Chapter 1: The Drop (ready)
  - [ ] Chapter 2: Awakening and Landing (ready)
  - [ ] Chapter 3: (next chapter)
  - [ ] Edit and proofread all chapters
  - [ ] Format for Substack (proper headings, spacing)

- [ ] **About Page:**
  - [ ] Story synopsis
  - [ ] Author bio
  - [ ] Publishing schedule
  - [ ] Contact information

- [ ] **Behind-the-Scenes Content:**
  - [ ] Character bios (Baebe, Taivalu, Ayumi, Aurek, Angel)
  - [ ] World-building notes (The City, O1, Undercity)
  - [ ] Concept art or visual references
  - [ ] Writing process notes

### Social Media Setup
- [ ] **Twitter/X:**
  - [ ] Create/update author account
  - [ ] Bio with Substack link
  - [ ] Pinned post about BAEBE
  - [ ] Profile image and header

- [ ] **Instagram:**
  - [ ] Create/update author account
  - [ ] Bio with Substack link
  - [ ] Profile image
  - [ ] Prepare visual content (quotes, concept art)

- [ ] **Reddit:**
  - [ ] Identify relevant subreddits (r/scifi, r/cyberpunk, r/books, r/writing)
  - [ ] Read community rules
  - [ ] Prepare introduction post

- [ ] **Goodreads:**
  - [ ] Create/update author profile
  - [ ] Add BAEBE as "currently writing"
  - [ ] Link to Substack

### Marketing Materials
- [ ] **Email Signature:**
  - [ ] Add Substack link
  - [ ] Add social media links
  - [ ] Brief tagline

- [ ] **Social Media Graphics:**
  - [ ] Chapter announcement template
  - [ ] Quote graphics template
  - [ ] Behind-the-scenes graphics template

- [ ] **Press Kit (Optional):**
  - [ ] Author bio
  - [ ] Story synopsis
  - [ ] High-res author photo
  - [ ] Book cover/concept art
  - [ ] Contact information

## Launch Week Checklist (Week 2)

### Pre-Launch (Days 1-3)
- [ ] **Day 1:**
  - [ ] Publish welcome post
  - [ ] Publish Chapter 1 (free)
  - [ ] Share on personal social media
  - [ ] Email friends and family

- [ ] **Day 2:**
  - [ ] Publish Chapter 2 (free)
  - [ ] Share on Twitter/X
  - [ ] Post on Instagram
  - [ ] Engage with any comments

- [ ] **Day 3:**
  - [ ] Publish Chapter 3 (free)
  - [ ] Share on Reddit (relevant communities)
  - [ ] Post on Goodreads
  - [ ] Respond to all comments

### Launch Day (Day 4)
- [ ] **Announce Paid Tier:**
  - [ ] Publish announcement post
  - [ ] Explain paid tier benefits
  - [ ] Offer founding member pricing (limited time)
  - [ ] Create urgency (early bird pricing)

- [ ] **Marketing Blitz:**
  - [ ] Email all contacts
  - [ ] Post on all social media platforms
  - [ ] Share in relevant communities
  - [ ] Reach out to book bloggers (if ready)

- [ ] **Engagement:**
  - [ ] Respond to all comments
  - [ ] Thank early subscribers
  - [ ] Engage with social media mentions
  - [ ] Create discussion threads

### Post-Launch (Days 5-7)
- [ ] **Day 5:**
  - [ ] Publish first paid chapter (if have paid subscribers)
  - [ ] Or: Publish bonus content (character bio, behind-the-scenes)
  - [ ] Share subscriber milestone (if any)
  - [ ] Continue marketing

- [ ] **Day 6:**
  - [ ] Engage with community
  - [ ] Respond to comments
  - [ ] Share on social media
  - [ ] Plan next week's content

- [ ] **Day 7:**
  - [ ] Review metrics (subscribers, engagement)
  - [ ] Analyze what worked
  - [ ] Plan improvements
  - [ ] Prepare next week's chapters

- [ ] **Bonus Content (Weekly):**

  - [ ] Character bio

  - [ ] Writing process update
  - [ ] Q&A or discussion thread

  - [ ] Instagram: Visual content, quotes, behind-the-scenes
  - [ ] Reddit: Share in relevant communities (once per week per subreddit)

- [ ] **Email Newsletter:**
  - [ ] Weekly newsletter to subscribers
  - [ ] Chapter announcements
  - [ ] Exclusive content
  - [ ] Community updates

- [ ] **Community Engagement:**
  - [ ] Respond to all comments (within 24 hours)
  - [ ] Create discussion threads
  - [ ] Answer questions
  - [ ] Thank subscribers

### Monthly Review
- [ ] **Metrics Review:**
  - [ ] Free subscribers count
  - [ ] Paid subscribers count
  - [ ] Conversion rate
  - [ ] Revenue (MRR, ARR)
  - [ ] Engagement metrics (open rate, comments, shares)

- [ ] **Content Review:**
  - [ ] What chapters performed best?
  - [ ] What content resonated?
  - [ ] What feedback did you receive?
  - [ ] What improvements needed?

- [ ] **Strategy Adjustments:**
  - [ ] Adjust pricing (if needed)
  - [ ] Adjust publishing schedule (if needed)
  - [ ] Adjust content strategy (if needed)
  - [ ] Adjust marketing strategy (if needed)

## Success Metrics to Track

### Subscriber Metrics
- [ ] Free subscribers (target: 5,000-10,000+)
- [ ] Paid subscribers (target: 200-1,000+)
- [ ] Conversion rate (target: 5-10%)
- [ ] Churn rate (target: <5% monthly)

### Revenue Metrics
- [ ] Monthly recurring revenue (MRR)
- [ ] Annual recurring revenue (ARR)
- [ ] Average revenue per user (ARPU)
- [ ] Lifetime value (LTV)

### Engagement Metrics
- [ ] Open rate (target: 40%+)
- [ ] Click rate (target: 5-10%)
- [ ] Comment rate (target: 5-10%)
- [ ] Share rate (target: 2-5%)

### Content Metrics
- [ ] Most popular chapters
- [ ] Most engaged content
- [ ] Best performing posts
- [ ] Reader feedback

## Troubleshooting Checklist

### Low Subscriber Growth
- [ ] Review marketing strategy
- [ ] Increase social media presence
- [ ] Engage more in communities
- [ ] Partner with other writers
- [ ] Improve free chapters (hook better)

### Low Conversion (Free to Paid)
- [ ] Review value proposition
- [ ] Improve paid tier benefits
- [ ] Test pricing ($5 vs. $10)
- [ ] Create urgency (limited time offers)
- [ ] Add social proof

### High Churn Rate
- [ ] Review content quality
- [ ] Maintain publishing schedule
- [ ] Increase engagement
- [ ] Add more exclusive content
- [ ] Survey churned subscribers

### Low Engagement
- [ ] Respond to comments more
- [ ] Create discussion threads
- [ ] Ask questions
- [ ] Share behind-the-scenes
- [ ] Build community
