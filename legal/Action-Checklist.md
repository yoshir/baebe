## Immediate Actions (Do This Week)

### 1. Copyright Registration
- [ ] Register BAEBE with US Copyright Office
- [ ] Cost: $45-$125 (electronic filing recommended)
- [ ] Timeline: File immediately (before any agreements)
- [ ] Owner: You (not Optimal Anarchy)
- [ ] **Priority: CRITICAL - Do this first**

**How to Register:**
1. Go to copyright.gov
2. Create account
3. File electronic application
4. Upload BAEBE files
5. Pay fee ($45-$125)
6. Receive confirmation (certificate in 3-6 months)

**What to Register:**
- BAEBE novel/story (all versions)
- Character names, storylines, world-building
- All formats (novel, screenplay, etc.)

---

### 2. Document Creation Timeline
- [ ] Gather all BAEBE files with dates
- [ ] Document when you created the story
- [ ] Save dated drafts, notes, outlines
- [ ] Create timeline document
- [ ] **Purpose: Prove you created IP before company/investment**

**What to Document:**
- First draft date
- Revision dates
- File creation dates
- Notes/outlines dates
- Any communications about creation

**How to Document:**
- Create folder: "BAEBE-Creation-Timeline"
- Save all files with dates
- Create written timeline
- Keep backups

---

### 3. Review Existing Agreements
- [ ] Find all investment agreements
- [ ] Review what they say about IP
- [ ] Check company formation documents
- [ ] Identify any IP assignment clauses
- [ ] **Purpose: Understand current legal status**

**What to Look For:**
- IP assignment language
- Work-for-hire clauses
- IP ownership statements
- Any IP-related terms

**If You Find Issues:**
- Note them for attorney
- Don't sign new agreements until resolved
- Get attorney review

### 6. Draft License Agreement
- [ ] Engage attorney to draft
