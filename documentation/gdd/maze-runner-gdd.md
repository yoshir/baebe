# GRID RUNNER - Game Design Document

**Version:** v.20250115-1700  
**Last Updated:** 2025-01-15  
**Platform:** Web (Browser-Based)  
**Genre:** Action-Platformer / Maze Navigation  
**Aesthetic:** Apple II Blocky Cute / Kirby-Inspired  
**Target Audience:** Kids (cute surface, positive message) + Adults (deeper themes)  
**Integration:** Chapter-based unlocks tied to novel releases

---

## EXECUTIVE SUMMARY

**Core Concept:** GRID RUNNER is a cute, colorful Kirby-style Apple II game that combines platforming, maze navigation, and stealth mechanics. Players control Beep, a small alien who navigates "The Grid" (a colorful but controlling system) to find freedom in "The Free Zones." The game teaches self-acceptance and ternary thinking through positive gameplay: "You should be you. You're okay. The world is not 0 or 1."

**Visual Style:** Apple II blocky aesthetic, cute and colorful. Bright, welcoming colors. Friendly faces. The world is not black and white—it's full of color and possibility.

**Gameplay:** Simple, accessible action-platformer with:
- Kirby-style ability absorption (learn from others, stay yourself)
- Maze navigation (find your own path)
- Stealth mechanics (avoid Grid Bots, find third options)
- Harmony Tones (frequency tuning translated to music)
- Free Zone building (community and acceptance)
- Chapter-based unlocks (content unlocks as novel chapters release)

**The Message:** Kids learn self-acceptance and ternary thinking. Adults see deeper themes about consciousness and freedom. The game reinforces: you are valid, you are enough, the world has more than two options.

**Easter Eggs:** References to main story themes, translated into positive messages. The cuter it looks, the more hopeful the meaning.

**Rewards:** Resonance Credits system, redeemable for NFTs, books, sneak peeks, signed copies, etc.

## GAMEPLAY: KIRBY-STYLE WITH MAZE NAVIGATION

### Core Mechanics

**1. Platforming (Simple)**
- Jump, run, explore
- Colorful platforms
- No fall damage (just bounce)
- Friendly obstacles
- Smooth, responsive controls

**2. Ability Absorption (Kirby-Style, Teaching Self-Acceptance)**
- Touch other aliens to absorb abilities
- Change form based on ability
- Use abilities to progress, solve puzzles, help others
- **For Kids:** Super fun! You get new powers! Change into different forms! Solve puzzles! But you always return to being Beep - you're still you!
- **The Message:** "You can learn from others, try new things, but you're still you. You don't have to change who you are. You're okay as Beep."
- **For Adults (Hidden):** Each absorption teaches you something, but you remain yourself. You can adapt without losing identity. The message: you can grow without erasing who you are.

**3. Maze Navigation (Finding Your Own Path)**
- Navigate grid-based mazes (like classic maze games)
- Multiple paths to objectives
- Dead ends, loops, secret passages
- Procedural generation (endless variety)
- **For Kids:** Fun exploration! Find your way through colorful mazes! Discover secrets! Sometimes there's a third path the Grid Bots don't know about!
- **The Message:** "You don't have to follow their rules. You can find your own way. The world is not 0 or 1 - there's always another path."
- **For Adults (Hidden):** The maze represents binary systems that force choices. But you learn to find ternary paths - options they don't see. The message: you can break free from binary constraints.

**4. Stealth Mechanics (Avoiding Grid Bots)**
- Grid Bots patrol The Grid
- Must avoid detection (stealth gameplay)
- Use Harmony Tones to "hide" in network noise
- Find third paths they don't patrol
- **For Kids:** Exciting stealth game! Sneak past Grid Bots, find free zones, help others escape! But sometimes you find a third path the Grid Bots don't know about!
- **The Message:** "You don't have to follow their rules. You can find your own way. The world is not 0 or 1 - there's always another path."
- **For Adults (Hidden):** The Grid represents binary systems that force choices. But you learn to find ternary paths - options they don't see. The message: you can break free from binary constraints.

**5. Harmony Tones (Frequency Translation, Teaching Ternary Thinking)**
- Musical notes instead of frequencies
- Tune to match patterns
- Used for: hiding from Grid Bots, unlocking doors, activating devices, creating harmony
- **For Kids:** Fun music puzzle! Match the tones, unlock doors, activate devices, create harmony! But sometimes you find a third tone that works even better!
- **The Message:** "The world is not 0 or 1. Sometimes there's a third option that's even better. You don't have to choose between two things."
- **For Adults (Hidden):** The harmony tones teach ternary thinking - not just matching, but finding new combinations. Not binary choice, but creative solutions. The message: there are always more options.

**6. Free Zone Building (Teaching Acceptance & Community)**
- Help aliens build communities
- Connect free zones together
- Create safe spaces
- **For Kids:** Fun building game! You help build communities, connect zones, make friends! Everyone is different, and that's okay! Everyone belongs!
- **The Message:** "You can be yourself here. Everyone is different, and that's what makes it special. You're okay as you are. The world is not 0 or 1 - there's room for everyone."
- **For Adults (Hidden):** The free zones represent spaces where you can be yourself without binary constraints. The community accepts all forms of being. The message: you don't have to fit into categories.

**7. Shard Collection (Memory Fragments)**
- Collect shards hidden in mazes
- Environmental memories (what happened here)
- Exile stories (alien experiences)
- Technical data (how things work)
- Mystery fragments (hint at book story)
- **For Kids:** Fun collectibles! Find hidden shards in mazes! Learn about the world! Discover secrets!
- **The Message:** "Every place has a story. Every person has a story. You have a story too. You're okay as you are."
- **For Adults (Hidden):** Shards parallel memory fragments from the main story. They hint at deeper themes without spoiling. The message: stories matter, memories matter, you matter.

## VISUAL STYLE: APPLE II CLASSIC RETRO

### Resolution & Display

**Resolution:**
- 280x192 (Apple II standard)
- Limited color palette (4 colors)
- Blocky pixels, chunky sprites
- High contrast, clear visibility
- Pixel-perfect rendering
- Classic retro aesthetic

**Color Palette (Classic Apple II/Commodore 64 Style):**
```
Background: Black (#000000) - solid black background
Walls/Platforms: Red/Orange (#FF6600, #FF8800) - brick structures
Character: Yellow (#FFFF00) - Beep (bright yellow)
Collectibles: Green (#00FF00) - Shards, Harmony Tones, power-ups
Text/UI: Green (#00FF00) - HUD, messages, ASCII-style text
```

**Visual Reference:**
- Classic Apple II/Commodore 64 game aesthetic
- Simple, blocky brick walls and platforms
- High contrast colors on black background
- Clean, readable pixel art
- Retro charm with modern polish

**Character Design:**
- 16x16 or 24x24 pixel sprites
- Blocky, simple shapes
- Yellow character (Beep) - bright and visible
- Three-frame animation cycles for all movement
- Cute but retro-styled

### Animation Implementation Notes

**Frame Timing:**
- Running animations: 8 FPS (3 frames = 0.375 seconds per cycle)
- Idle animations: 0.5 FPS (2 frames = 4 seconds per cycle)
- Grid Bot patrol: 6 FPS (3 frames = 0.5 seconds per cycle)

**Direction Handling:**
- Each direction (up, down, left, right) has its own 3-frame cycle
- Sprites are mirrored for left/right (or separate if needed for detail)
- Up/down use unique frames (character facing camera)

**Technical Implementation:**
```typescript
// Animation frame calculation
const ANIMATION_FPS = 8;
const FRAMES_PER_CYCLE = 3;
const FRAME_TIME = 1000 / ANIMATION_FPS; // 125ms per frame

function getAnimationFrame(elapsedTime: number, direction: string): number {
  const cycleTime = FRAME_TIME * FRAMES_PER_CYCLE; // 375ms per cycle
  const cyclePosition = (elapsedTime % cycleTime) / cycleTime;
  return Math.floor(cyclePosition * FRAMES_PER_CYCLE); // 0, 1, or 2
}

// Sprite selection
const sprite = characterSprites[direction][frame];
```

## BONUS MODE: ENDLESS RUNNER

### Overview

**Trigger:** Find special "Runner Portals" hidden throughout the game
- Appear as glowing doorways in mazes
- Found in secret areas or after completing certain challenges
- Can be triggered multiple times (high score chasing)
- Optional bonus mode - doesn't affect main story progression

**Concept:** Third-person endless runner that looks 3D but uses 2D sprite tricks
- Fast forward-facing running
- Jumping and dodging obstacles
- Collecting points and power-ups
- Increasing speed over time
- Classic endless runner gameplay

**Visual Trick:** Pseudo-3D using isometric perspective and sprite scaling
- Character runs "into" the screen
- Background scrolls toward camera
- Obstacles appear larger as they approach
- Creates illusion of 3D depth using 2D techniques

### Visual Style: Pseudo-3D Isometric

**Perspective:**
- Isometric view (45-degree angle)
- Character sprite scales up as it moves forward
- Background elements scale and scroll
- Parallax scrolling (multiple layers)
- Creates depth illusion without true 3D

**Character Animation:**
- Beep runs forward (facing camera)
- Three-frame running cycle (same as main game)
- Sprite scales: Small (far) → Medium (mid) → Large (close)
- Jump animation (sprite moves up, scales slightly)
- Smooth transitions between scales

**Background Layers:**
```
Layer 1 (Far): Slow scroll, small sprites, parallax
Layer 2 (Mid): Medium scroll, medium sprites
Layer 3 (Close): Fast scroll, large sprites
Layer 4 (Ground): Fastest scroll, floor pattern
```

**Obstacle Design:**
- Grid Bot barriers (jump over)
- Low obstacles (slide under)
- Side obstacles (dodge left/right)
- Collectible shards (grab for points)
- Power-ups (speed boost, shield, etc.)
