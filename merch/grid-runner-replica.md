# GRID RUNNER - Replica Game Merchandise

**Concept**: Physical replica of the GRID RUNNER handheld game from BAEBE novel

---

## Product Description

Authentic replica of the 1980s-style LCD handheld game featured in the BAEBE universe. The game that Chen gave to Kess, representing hope and survival in the post-Conversion world.

**Fictional Backstory** (for marketing):
- Pre-Conversion artifact from the 1980s
- Simple maze-runner game
- EMP-resistant due to basic circuits
- Survived 80 years in the ruins
- Symbol of persistence and family

---

## Physical Specifications

### Display
- **Type**: Custom segmented LCD (green monochrome)
- **Size**: 2.5" x 2" viewing area
- **Game graphics**:
  - Maze corridors (segmented paths)
  - Player figure (small character sprite)
  - 3 pursuer figures
  - Exit indicator
- **Style**: Retro 1980s Game & Watch aesthetic

### Housing
- **Material**: ABS plastic (injection molded)
- **Dimensions**: 4" x 3" x 0.5" (similar to original Game & Watch)
- **Color**: Weathered/distressed finish (optional: "clean" version also)
- **Buttons**: D-pad + action button
- **Screen cover**: Scratch-resistant clear plastic

### Power
- **Primary**: CR2032 watch battery (replaceable)
- **Optional**: Small solar cell on back (functional or decorative)
- **Battery life**: 100+ hours of gameplay

### Packaging
- Collectible box with BAEBE novel artwork
- Certificate of authenticity
- Backstory card (Chen's gift to Kess)
- Instruction manual (in-universe style)

## Manufacturing Costs

### Small Batch Production (500-1000 units)

**Per Unit Costs:**
- Custom LCD screen: $8-12
- PCB + components: $5-8
- Plastic housing (injection molded): $3-5
- Battery + compartment: $1-2
- Buttons + hardware: $1-2
- Solar cell (decorative): $2-3
- Assembly labor: $3-5
- **Total per unit: $23-37**

**One-Time Tooling:**
- LCD screen tooling: $25,000-35,000
- Injection mold (housing): $8,000-15,000
- PCB design + testing: $3,000-5,000
- **Total tooling: $36,000-55,000**

**Packaging:**
- Custom box design: $2,000-3,000
- Per unit packaging: $3-5

**Total First Run Cost (1000 units):**
- Tooling: $40,000
- Per unit: $28 x 1000 = $28,000
- Packaging: $5,000
- **Total: $73,000**
- **Per unit landed cost: $73**

### Alternative: Modern Parts (Lower Tooling)

**Using generic LCD modules instead of custom:**
- Generic LCD module: $8-12
- 3D printed housing: $4-6
- Same electronics: $5-8
- Assembly: $3-5
- **Per unit: $20-31**

**Reduced Tooling:**
- No custom LCD tooling: $0
- 3D print files instead of injection mold: $1,000
- PCB design: $3,000
- **Total tooling: $4,000**

**Total First Run (1000 units):**
- Tooling: $4,000
- Per unit: $25 x 1000 = $25,000
- Packaging: $5,000
- **Total: $34,000**
- **Per unit landed cost: $34**
