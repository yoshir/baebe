#### CAMERON PACING - When Does Action Happen?

**100% KINETIC - NO PAUSES**

**Action Flow:**
- Lines 1-500: FREE FALL - Constant velocity description, wind roaring, tactical overlay scrolling
- Dialogue happens DURING fall (not pause → talk → resume)
- Example: "Ghost One. I have visual—" **BUFFETED BY WIND** "—Deploying."
- Team check-ins WHILE falling: "Green?" "Green." "Green." **ATMOSPHERIC FRICTION HEATING**
- Fractal wing deployment = PHYSICAL ACTION interrupting communication
- Landing sequence = continuous kinetic (wings snapping, glass impact, boots locking)

**Ticking Clocks:**
- Altitude counter: "50,000 feet... 40,000... 30,000..."
- Wing deployment countdown: "Deployment in 3... 2... 1..."
- Team status checks every 10 seconds
- Building approaching through toxic fog

**No Static Exposition**: Every piece of worldbuilding delivered DURING movement
- Toxic fog visible WHILE falling through it
- Compute infrastructure described WHILE streaking past
- Mission parameters delivered via comms DURING descent
- Binary perfection shown through ACTIONS not explanations

**Example Execution:**
```
NOT: "Baebe prepared to deploy her wings. The fractal design was..."
YES: "Wings **SNAP** open. Fractal geometry catching atmosphere. Deceleration forces **SLAMMING** her forward. Still falling. Still calculating. Altitude: 20,000."
```

## CAMERON PACING MASTER PRINCIPLES

**Core Rule**: Exposition DURING action, never AS pause.

**Wrong Pattern**:
```
Arrive → Explain situation → Then act
Character thinks through options → Makes choice → Then executes
Discover information → Process it → Then react
```

**Right Pattern**:
```
Arrive → Act WHILE explaining → Interrupted by crisis
"I think we should—" → **EXPLOSION** → "RUN!" → deciding while moving
Sees information → "That means—" → **BOOM** → understanding while fleeing
```

**Ticking Clocks** (always present):
- Upload: 40%... 60%... 80%...
- Distance: 10 meters... 5 meters... 2 meters...
- Countdown: 30 seconds... 15... 10... 5...
- Structural: Cracking... groaning... BREAKING...

**Interrupted Dialogue**:
- "Because it erases—" **BOOM** "—us"
- "Your brother has—" **CRACK** "—the key"
- Not complete speeches, fragments in chaos

**Emotional Beats DURING Action**:
- Grief while running (not: stop to grieve, then run)
- Teaching while dying (not: teach, then die)
- Recognition while escaping (not: stop to recognize, then flee)
- Choice while countdown (not: countdown stops, choice made, then expires)

**The "Aliens" Test**:
If you can imagine Ripley stopping to explain something while NOT running/fighting/evading, you're doing it wrong. She explains WHILE the alien is approaching, WHILE the countdown is ticking, WHILE Newt is in danger.
