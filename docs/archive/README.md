# Documentation Archive

This directory is the destination for historical plans, handoffs, reviews, superseded proposals, and old execution records after provenance and links have been audited.

No historical files were moved as part of the tracking-process slice. Existing archives remain in their current locations so that creative work and historical links are not silently changed. A future archive-migration slice must record each source path, destination path, status (`REFERENCE`, `SUPERSEDED`, or `ARCHIVED`), provenance, and repaired links in the canonical roadmap before moving files.
